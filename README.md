# FocaFounderHack

Founder Hack 2024 — a productivity tracking app with AI screen analysis.

**Foca** monitors whether you're actually working on what you said you would. The
AI component (`Foca.ai`) captures your screen every ~5 seconds, sends it to
OpenAI, and checks whether the content matches your stated goal — producing a
boolean productivity score in real time.

**Status:** Hackathon prototype. Not maintained.

**Built:** August 2024 · Python, JavaScript, OpenAI API
